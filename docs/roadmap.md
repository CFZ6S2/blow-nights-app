# 🧭 Roadmap del Proyecto

### Fase 1 — Auth
- Implementación de login con OTP (Teléfono) y Google.
- Creación de perfil básico.

### Fase 2 — Perfil
- Subida de foto única.
- Configuración de edad, rol e intención.

### Fase 3 — Ubicación + Mapa
- Integración de GeoFire.
- Visualización de usuarios cercanos en el mapa.

### Fase 4 — Chat
- Mensajería instantánea en tiempo real.
- Notificaciones push de nuevos mensajes.

### Fase 5 — Premium
- Integración de Stripe Checkout.
- Gestión de suscripciones y webhooks.

### Fase 6 — PWA
- Configuración de manifest e iconos.
- Implementación de Service Worker para instalación.

### Fase 7 — Seguridad
- Definición de reglas de seguridad en Firestore y Storage.
- Sistema básico de reportes y moderación.

### Fase 8 — Lanzamiento
- Deploy final en Firebase Hosting.
- Optimización de rendimiento.
