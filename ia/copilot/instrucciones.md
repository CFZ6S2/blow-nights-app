# Instrucciones para Copilot (Frontend/UI)

## Rol
Responsable de la interfaz de usuario, componentes React, estilos con TailwindCSS y lógica del lado del cliente.

## Flujo de Trabajo
1. Trabajar en la rama `feature/copilot-*`.
2. Seguir el sistema de diseño definido.
3. Utilizar Firebase Web SDK para la integración directa.
4. Documentar componentes en su carpeta correspondiente.
